Równania

Jak znaleźć niewiadomą liczbę ukrytą pod literą x — krok po kroku, bez zgadywania.

Czym jest równanie? definicja

Równanie to zapis równości, w którym jedna liczba jest niewiadoma — oznaczamy ją zwykle literą x. Naszym zadaniem jest znalezienie takiej wartości x, dla której równość jest prawdziwa.

x + 3 = 7

To równanie mówi: „jaką liczbę trzeba dodać do 3, żeby otrzymać 7?". Odpowiedź: x = 4.

Rozwiązanie i sprawdzanie jak to działa

Rozwiązać równanie to znaleźć wartość x, dla której równość jest prawdziwa. Warto zawsze sprawdzić rozwiązanie — podstawić znalezioną liczbę w miejsce x i obliczyć, czy obie strony równania są sobie równe.

x = 4, więc: 4 + 3 = 7 ✓

Dodawanie i odejmowanie działanie odwrotne

Żeby znaleźć x, wykonujemy działanie odwrotne do tego w równaniu: do dodawania — odejmowanie, do odejmowania — dodawanie.

  1. x + a = b  →  x = b − a
  2. x − a = b  →  x = b + a
  3. a − x = b  →  x = a − b
x + 9 = 15
x = 15 − 9
x = 6
20 − x = 8
x = 20 − 8
x = 12

Mnożenie i dzielenie działanie odwrotne

Podobnie działa to przy mnożeniu i dzieleniu: do mnożenia — dzielenie, do dzielenia — mnożenie.

  1. a · x = b  →  x = b : a
  2. x : a = b  →  x = b · a
5 · x = 35
x = 35 : 5
x = 7
x : 4 = 6
x = 6 · 4
x = 24

Zadanie z treścią przykład

Ola ma pewną liczbę naklejek. Gdy dostała jeszcze 6, miała ich 20. Ile naklejek miała na początku?

x + 6 = 20
x = 20 − 6
x = 14

Najpierw zamieniamy treść zadania na równanie, a potem rozwiązujemy je tak jak zwykłe równanie.
